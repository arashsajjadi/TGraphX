# TGraphX v1.5.1 — canonical set-attention naming + exact reference configuration

Backward-compatible **patch** release. No behavior change for existing
code: every import, config, checkpoint, and pickled model from 1.5.0
continues to work, and all constructor defaults are unchanged.

## Canonical name

The learned-implicit-relations family's canonical public class is now

```python
from tgraphx import TGraphXSetAttention   # canonical
from tgraphx import SetTransformerModel   # permanent compatibility alias
assert SetTransformerModel is TGraphXSetAttention
```

Paper/table label: **TGraphX-SetAttn**. Stable machine name in configs
and the factory: `"set_transformer"`; the factory additionally accepts
`family="set_attention"` and `family="tgraphx_set_attention"` as
aliases. Topology source: `"learned_implicit"` — global content-based
relation learning over tensor-valued entities without requiring a
supplied edge graph.

## New explicit architecture axes (defaults unchanged)

- `norm_order="pre"|"post"` (post-LN = the
  `torch.nn.TransformerEncoderLayer` convention)
- `activation="gelu"|"relu"`
- `pool_attention_dropout` (decouple readout dropout from block
  `attention_dropout`)
- `head_hidden_dim` (optional two-layer head)
- `encoder_config={"architecture": "strided", ...}` selecting the new
  `StridedConvEncoder` (channel-growing strided convolutions; explicit
  `channel_schedule` supported); `"cnn"` remains the default.

## Evaluated reference configuration

```python
cfg = TGraphXSetAttention.reference_config(in_shape=(13, 32, 32), num_classes=18)
model = TGraphXSetAttention(**cfg)
model.load_state_dict(
    TGraphXSetAttention.map_reference_state_dict(reference_ckpt_state), strict=True)
```

reconstructs the exact set-attention instance evaluated in the TGraphX
experiment program. Verified against the completed revised-experiment
checkpoints: identical parameter count (189,650), strict state-dict
load, logits within 2.4e-06 on a fixed real validation batch, and
identical predictions on the full validation split for all five seeds
(every recorded per-seed macro-F1 reproduced exactly; mean
0.7023 ± 0.0146). Details:
[../reports/SET_ATTENTION_REFERENCE_PARITY.md](../reports/SET_ATTENTION_REFERENCE_PARITY.md).

The class *defaults* (pre-LN, GELU, dropout 0.0, `CNNEncoder`) are
deliberately unchanged and remain a general-purpose construction — the
evaluated architecture is selected only by the explicit reference
configuration.
