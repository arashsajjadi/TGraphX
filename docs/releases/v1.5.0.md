# TGraphX v1.5.0 — tensor-relational platform release

Released 2026-07-27. Semantic-version **MINOR**: backward-compatible
model-family addition plus a loud (never silent) configuration-semantics
fix.

## 1. SetTransformer — learned implicit relations

New first-class family for the regime where entities vary in number and
no trusted `edge_index` exists:

```python
from tgraphx import build_model

model = build_model(
    task="graph_classification", family="set_transformer",
    in_shape=(13, 32, 32), hidden_shape=(64,), num_layers=2,
    num_classes=18, heads=4, dropout=0.0,
)
```

`SetTransformerModel` = shared tensor node encoder → masked pre-LN
multi-head self-attention blocks (permutation-equivariant) →
permutation-invariant readout (attention/PMA, mean, sum, or max) →
linear head. Variable-size sets ride the standard flat
`GraphBatch` convention; `fit`/`evaluate`/checkpoints/experiment runner
work unchanged; CPU and CUDA; PyTorch primitives only.

It is **relation-aware but explicit-input-topology-blind**: attention
learns content-dependent pairwise interactions, and a supplied
`edge_index` is never consumed (warned once by default; see below). It
is not TensorGAT (which attends only over supplied edges) and not
learned explicit topology (`tgraphx.learned_graph`).

## 2. Explicit dropout configuration

TGraphX ≤ 1.4.2 silently applied `dropout_prob=0.3` inside `CNNEncoder`
and `DeepCNNAggregator` (reached via `ConvMessagePassing`,
`GraphClassifier`, `CNN_GNN_Model`), and `make_layer("conv",
dropout=X)` / `build_model(layer="conv", dropout=X)` ignored `X`.
Controlled re-runs measured the hidden 0.3 at ≈ −0.04 to −0.06
validation macro-F1 on PASTIS-R.

v1.5.0: the documented default is **0.0**; omitting the value emits
`DropoutDefaultChangeWarning`; the effective value is visible in
`repr()`, `.dropout_prob`, and `.config()`; the factories forward
`dropout` / `use_batchnorm` / `aggregator_params` for `conv`;
conflicting settings raise instead of silently picking one.

## 3. Hidden-dropout migration guidance

See [docs/migration_v1_4_to_v1_5.md](../migration_v1_4_to_v1_5.md).
Short version: pass `dropout_prob` (or factory `dropout`) explicitly —
any value silences the warning. To reproduce pre-1.5 behaviour exactly,
use `dropout_prob=0.3`, `CNNEncoder.legacy(...)`,
`DeepCNNAggregator.legacy(...)`, or `LEGACY_CNN_DROPOUT_PROB`.

## 4. Topology-source / model-family metadata

`TOPOLOGY_SOURCES = ("none", "fixed", "given", "learned_implicit",
"learned_explicit", "hybrid")`; `topology_source_of(family)`; every
`build_model` output carries `model.model_family` and
`model.topology_source`; `SetTransformerModel.config()` records both.
Models that ignore supplied topology say so: `TopologyIgnoredWarning`
once per instance (configurable `on_edge_index="warn"|"ignore"|"error"`).
Regime guide: [docs/tensor_relational_platform.md](../tensor_relational_platform.md).

## 5. Backward compatibility

- All v1.3.x/v1.4.x public APIs keep their signatures; new constructor
  parameters are keyword-optional.
- Checkpoints load unchanged in both directions (dropout has no
  parameters; eval outputs never depended on it). Loaded legacy
  checkpoints are never silently altered.
- The only behavioural change is training-time regularization for code
  that relied on the silent 0.3 — announced per construction site by
  the warning, with an explicit legacy path.
- `use_batchnorm` / `use_residual` defaults unchanged (checkpoint
  layout); now visible in `repr()`/`config()`.

## 6. Testing summary

- New: `tests/test_explicit_dropout_v150.py` (22 tests),
  `tests/test_set_transformer_v150.py` (37 tests): configured==effective
  dropout, zero-dropout has no active path, repr/config/checkpoint
  parity, legacy reconstruction, factory regression tests for the
  silent-0.3 bug; SetTransformer shapes, variable set sizes,
  padding-mask isolation, permutation invariance/equivariance, gradient
  reach, CPU/CUDA parity, deterministic construction, config and
  checkpoint round trips, edge_index contract, registry/batching/
  evaluator integration, and two tiny synthetic sanity checks
  (explicitly non-scientific).
- Full suite at release: **3412 passed, 23 skipped** (local run with
  CUDA available; count includes GPU tests).

## 7. Scientific evidence: reused, not rerun

**No PASTIS-R experiments were rerun for this release.** All numbers in
the documentation are reused from the frozen `TGraphX_revised`
artifacts (5 paired seeds, frozen splits, matched budgets, best-val
selection, sha256-manifested). Headline (validation macro-F1, S2-only):
SetTransformer 0.7023 · TemporalTransformer 0.6914 · PairSet 0.6520 ·
corrected TGraphX 0.6326 · fixed CNN 0.6196 · DeepSets 0.6099 · flatten
GNN 0.6012. Multimodal Branch B: SetTransformer 0.6593 · real-topology
TGraphX 0.6306 · shuffled-topology 0.5718 (topology signal is real:
+0.059 vs shuffled, +0.049 vs matched-content blind). Interpretation
and caveats — including the frozen geographic test where all models
drop sharply and the correction gain does not transfer — are in
[docs/tensor_relational_platform.md](../tensor_relational_platform.md)
and the internal engineering report
([docs/reports/TENSOR_RELATIONAL_PLATFORM_UPDATE.md](../reports/TENSOR_RELATIONAL_PLATFORM_UPDATE.md)).

Phrasing note: among the platform's tested relation modes, learned
global set attention performed best on this natural-label task, while
supplied topology provided an additional measurable signal. That is a
platform/family-level result — not evidence that any single
message-passing operator "won" or "lost".
